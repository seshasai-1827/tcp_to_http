# HTTP Server in C

A simple HTTP server built from scratch using POSIX sockets and the TCP/IP stack.

## Learning Goals

- Learn the POSIX socket API
- Understand TCP connection management
- Understand the HTTP/1.1 request-response model
- Practice systems programming in C
- Explore Linux networking and file descriptors

## Roadmap

- [x] Create TCP socket
- [x] Bind to a local address
- [x] Listen for incoming connections
- [x] Accept client connections
- [x] Receive HTTP requests
- [x] Parse HTTP headers
- [x] Send valid HTTP responses
- [ ] Sending Bytes
- [ ] Serve static HTML pages
- [ ] Serve images
- [ ] Stream MP4 video
- [ ] Handle multiple concurrent clients
